# 迁移与还原记录

来源：用户提供并解锁的 https://lucy-lu.com/ ，以及该页面加载的公开发布素材与布局模块。没有执行下载的 Framer 模块；一次性解析其声明式布局、文字、图片、样式、响应式变体和动画配置，转换成普通静态页面描述。

## 2026-10-19 还原更新

- 恢复首页黑色 Hero、浅色作品区、白色作品卡片与白色联系区。
- 恢复原站桌面、平板和手机布局，案例正文保留多列、横排、图文对应关系与分组，而非统一纵向排列。
- 恢复所有实际引用的本地字体，包括 Neue Montreal、Sharp Grotesk、Satoshi、Poppins、Inter 及斜体变体。
- 桌面卡片封面由 520px 收到 420px，平板由 400px 收到 312px，露出底部按钮。保留按钮、社交图标的颜色状态及弹簧过渡；键盘焦点也可显示卡片操作。
- 恢复纵向职业标签、横向连续图片组、手动轮播及拖动、入场淡入和位移/旋转。连续轨道按原速度、间距与方向运行；弹簧入场依据原质量、阻尼和刚度计算。
- 共用导航、联系区、按钮和卡片使用共享组件描述。文字只存一份，三个断点按引用使用。
- 本地素材在首轮基础上补充 2 张遗漏图片和 10 个字体文件。保留 GIF 动画，无 Framer 运行时、CDN 或分析脚本依赖。
- 保留首次迁移的 103 个章节锚点（三种布局共 309 处映射），以及原站五条页面路径；统一路径映射支持改名、隐藏和新增首页作品入口。
